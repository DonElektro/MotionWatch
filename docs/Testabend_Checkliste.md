# Motion Watch – Checkliste für den Testabend

Ziel: einmal alles mit der echten Hardware ausprobieren, bevor es auf den Campingplatz geht.
Plane etwa 2 Stunden ein und mach den Test, wenn es dunkel ist. Hake ab, was klappt. Was nicht klappt, notierst du in der Spalte daneben.

## 1. Vorbereitung (Tageslicht, ca. 20 min)

| ✓ | Was | Notiz |
|---|-----|-------|
| ☐ | Pi 5 mit Kamera, Servos, Wärmebildkamera, Mikrofon, Lautsprecher und Temperaturfühler zusammengebaut | |
| ☐ | Powerbank voll geladen; Startzeit notiert, um die Laufzeit zu messen | |
| ☐ | Pi startet von selbst (Autostart), nach ca. 1 min ist die Seite erreichbar | |
| ☐ | Handy verbindet sich mit dem Handy-Hotspot oder mit dem WLAN «MotionWatch» | |
| ☐ | Seite auch über **https** geöffnet (für Standort und Mikrofon) | |
| ☐ | Passwort gesetzt | |
| ☐ | **🩺 Selbstdiagnose**: alle Ampeln grün oder bewusst grau (aus) | |

## 2. Einzelteile prüfen (ca. 30 min)

| ✓ | Was | So prüfst du es | Notiz |
|---|-----|-----------------|-------|
| ☐ | Kamera | Live-Bild scharf, FPS-Anzeige über 5 | |
| ☐ | Servos | Joystick nach links/rechts/oben/unten, «Mitte», Wegpunkte anfahren | |
| ☐ | Patrouille | Schnellschalter «Patrouille», beide Arten (Pendel / Runde) | |
| ☐ | KI | Durchs Bild gehen → «Person» erscheint | |
| ☐ | Wärmebild | Hand vor die Wärmebildkamera → warme Stelle sichtbar | |
| ☐ | Mikrofon | Klatschen → Pegel schlägt aus | |
| ☐ | Lautsprecher | «Testton», dann «Sirene jetzt» (Lautstärke für die Nachbarn bedenken) | |
| ☐ | Licht / IR | Schnellschalter Licht und IR-Licht | |
| ☐ | Temperaturfühler | Wert in der Kopfzeile plausibel (mit einem Thermometer vergleichen) | |
| ☐ | Standort | Einstellungen → Standort: automatisch vom Handy oder auf der Karte gewählt | |
| ☐ | Push | «Test-Nachricht senden» kommt auf dem Handy an | |
| ☐ | Karte / Wetter | Kartenhintergrund sichtbar; Wetter einschalten → Tagesübersicht zeigt Wetter | |

## 3. Die Nacht (ab Dämmerung)

| ✓ | Was | Notiz |
|---|-----|-------|
| ☐ | **«🌙 Heute Nacht bewachen»** antippen; «Fehlt noch» ist leer | |
| ☐ | Nachtsicht schaltet sich bei Dunkelheit selbst ein | |
| ☐ | Nach dem Countdown durchs Bild gehen → Push-Nachricht mit Bild kommt (Zeit messen: ____ s) | |
| ☐ | Aufnahme ist unter «Aufzeichnungen» abspielbar, mit Ton | |
| ☐ | Fehlalarme in der ersten Stunde gezählt: ____ – jeden mit **👎 «War nichts»** markieren | |
| ☐ | CPU-Temperatur nach 1 Stunde: ____ °C (ab 70 °C gelb, ab 80 °C rot) | |
| ☐ | Unterspannung? (🩺 Stromversorgung) | |

## 4. Am Morgen

| ✓ | Was | Notiz |
|---|-----|-------|
| ☐ | Nachtbericht kam als Push (Standard 7 Uhr) | |
| ☐ | Tagesübersicht im Tagebuch: Temperaturkurve, Ereignisse, Bilder | |
| ☐ | Fehlalarm-Vorschläge unter «Aufzeichnungen» angesehen und eventuell übernommen | |
| ☐ | Powerbank-Laufzeit: Start ____ Uhr, leer / Reststand ____ | |
| ☐ | Speicherplatz nach der Nacht: ____ GB frei | |

## 5. Rückmeldung

Schick mir die Notizen. Ein Foto dieser Liste reicht.
Bei Problemen hilft ein Bildschirmfoto der **🩺 Selbstdiagnose** und des **Ereignisprotokolls**.
Damit kann ich gezielt nachbessern.
