# Testliste für das CI (.github/workflows/ci.yml) - EINE Zeile pro Test. Ausgeführt von werkzeuge/ci_lauf.py.
#
#   Gruppe | Limit (min) | Nochmal | Befehl | Was geprüft wird
#
# Neuen Test einhängen: eine Zeile in die passende Gruppe (am Ende der Gruppe), sonst nichts - ci.yml bleibt wie es ist.
# Jede Datei werkzeuge/*_test.py MUSS hier stehen (sonst wird «ci_lauf.py --pruefen» im Job «MoveEye» rot): entweder in
# einer Gruppe oder in der Gruppe «hand» mit dem Grund, warum sie nicht automatisch läuft.
#
# Gruppen (jede Gruppe = ein eigener, paralleler Job; welche Gruppe wann läuft: werkzeuge/ci_auswahl.py):
#   basis          ohne Browser: Bau, Selbsttest, Zusatzdatei, Update, Versionen            - läuft immer
#   kern           Web: jede Seite, Texte, Kopf, Protokoll                                  - bei jeder Änderung am Programm
#   rechte         Web: Benutzer, Rechte, PIN, Sicherheit                                   - bei jeder Änderung am Programm
#   live           Web: Live-Bild, Kameras, Ansichten                                       - bei jeder Änderung am Programm
#   daten          Web: Datentausch, Stimme, Simulator intern, Werkstatt, Bausatz           - bei jeder Änderung am Programm
#   spiele-1       Spielesammlung (alles ausser «Was nun?»), Kacheln, fertige Spiele        - nur bei Änderungen an Spielen, auf main immer
#   spiele-2       «Was nun?» (allein etwa 13 Minuten, gemessen 11.11.2026), Schach zu zweit - nur bei Änderungen an Spielen, auf main immer
#   simlive        gegen einen laufenden Simulator (Job «Simulator · läuft», Adresse in $SIM) - wenn die Godot-Tests laufen
#   pidienst       MoveEye unter echtem systemd wie auf dem Pi (Job «Pi-Dienst», Pakete von Bookworm, root über sudo)
#                  - bei Start / Update / Web-Server / Dienst (ci_auswahl.py PIDIENST_QUELLE), auf main immer
#   hand           läuft nicht im CI - der Grund steht in der letzten Spalte
#
# Limit: nach so vielen Minuten wird der Test abgebrochen (rot). Nochmal: «1x» = bei Rot genau EIN zweiter Versuch (nur für
# Tests, die auf einem vollen Rechner bekanntermassen wackeln; ein Erfolg erst im zweiten Versuch wird als Warnung gemeldet),
# «-» = kein zweiter Versuch. Im Befehl: $MW = die neueste webcam_bewegung_X_Y_Z.py, $CI_STRENG = «--streng» auf main,
# $SIM = Adresse des laufenden Simulators. Der Befehl darf kein « | » enthalten (Trennzeichen der Spalten).
