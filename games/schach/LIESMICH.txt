Schach für MoveEye
==================

Ein Schachspiel für die Spielecke von MoveEye, zusammengestellt aus freien Bausteinen. Alles liegt in diesem Ordner,
zur Laufzeit wird nichts aus dem Internet geholt.

---------------------------------------------------------------------------------------------------------
  npm install --ignore-scripts @lichess-org/chessground@10.5.0 chess.js@1.4.0 js-chess-engine@2.4.6 stockfish@19.0.1 esbuild@0.28.2

  e_cg.js:     import { Chessground } from '@lichess-org/chessground'; globalThis.Chessground = Chessground;
  e_chess.js:  import { Chess } from 'chess.js'; globalThis.Chess = Chess;
  e_jce.js:    import * as jce from 'js-chess-engine'; globalThis.JsChessEngine = jce;

  npx esbuild e_cg.js    --bundle --format=iife --target=es2019 --outfile=lib/chessground.js
  npx esbuild e_chess.js --bundle --format=iife --target=es2019 --outfile=lib/chess.js
  npx esbuild e_jce.js   --bundle --format=iife --target=es2019 --platform=browser --outfile=lib/js-chess-engine.js

Nicht verkleinert, also lesbar. Die CSS-Dateien und die beiden Stockfish-Dateien sind Kopien aus den npm-Paketen.

Aufbau der eigenen Dateien
--------------------------
  partie.js            Regeln und Partie ohne Bildschirm: Startstellung (FEN) + Zugliste (UCI); partie.zug(...) ist der
                       eine Weg für jeden Zug und liefert den neuen Zustand. Läuft auch in Node.
  motor.js             Rechner im Web Worker: zuerst Stockfish (WebAssembly); lädt er nicht (9 s) oder antwortet er nicht
                       (Bedenkzeit + 5 s), übernimmt motor-js-worker.js (js-chess-engine). Die Info-Zeile zeigt, wer rechnet.
  schach.js            Ablauf: Spieler-Objekte (Mensch, Motor; später «fern»), spiel.ziehe(uci), Stufen, Tipp, Lern-Modus,
                       Bewertungsbalken, Töne (WebAudio), Speichern (localStorage «moveeye-schach-einst» / «-partie»).
  index.html           Seite und Aussehen. Mit ?test=1 gibt es window.__schach für werkzeuge/spiele_test.py,
                       mit ?motor=js rechnet von Anfang an der Ersatz-Motor.

  fern.js              Zwei Handys über MoveEye: Verbindung zum Pi (MoveEye-Teil 639zzr) unter «…/schachfern/» am gleichen
                       Ursprung wie die Seite (Spiele-Port, Hauptadresse mit Anmeldung, Gäste-Link /p/<schlüssel>/, /spiele).
                       Long Polling (bis 15 s), sonst kurzes Abfragen; Code + Sitz-Schlüssel in localStorage
                       («moveeye-schach-fern»), nie in Link oder QR-Code. Ohne MoveEye (Datei direkt geöffnet) bleibt der
                       Modus «Zwei Handys» mit einem Hinweis aus.

Zwei Handys («Zwei Handys» im Fenster «Neues Spiel»): ein Handy erstellt das Spiel und zeigt einen Code aus 4 Zeichen und
einen QR-Code (Adresse der Seite + Code), das zweite tritt mit dem Code bei, weitere schauen zu. Der Pi hält nur Start-
stellung + Zugliste und prüft jeden Zug selbst (eigene kleine Regel-Prüfung in Python, mit chess.js verglichen:
werkzeuge/schach_fern_test.py). Remis, «Zug zurück» und Revanche (Farben getauscht) brauchen das Ja des Gegners. Tipps,
Lern-Modus und Balken rechnen nur auf dem eigenen Handy (bei zwei Handys zuerst aus); beide sehen «Tipps sind an», wenn
einer sie nutzt. In diesem Ordner liegt kein Server-Code.

Vorziehen (Premove, ab GS-1.18): während der Gegner (Computer oder das andere Handy) dran ist, darf man einen Zug
vorziehen (Ziehen oder Tippen, blau markiert). Kommt der Gegenzug, wird er sofort gespielt, wenn er dann erlaubt ist,
sonst still verworfen. Einer zur Zeit; Tippen auf ein leeres Feld, neben das Brett oder «✕ Vorzug» hebt ihn auf.
Umwandlung immer zur Dame. Aus im Lern-Modus und zu zweit an einem Gerät; Schalter «Vorziehen (Premove)» in den
Einstellungen. Bei zwei Handys bleibt er auf dem Handy, zum Pi geht nur der gespielte Zug mit seiner Zugnummer.
